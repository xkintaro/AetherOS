## Project requirements

- All OS interface text, prompts and error messages must be in English. Preserve the user's own file contents as written.

- Work locally only. Do not upload source, create hosted sites, deploy, or publish unless the user explicitly requests it.
- Keep the interface functional and minimal. Do not add filler applications, marketing panels, inactive controls, or differently labeled buttons for the same destination.
- Do not add decorative information blocks or repeated privacy/local-storage assurances. Keep explanatory text only when it helps use a control or understand a consequential action.
